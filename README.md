# Mangan Tako 🍽️
Bringing the authentic flavors of the Cordilleras right to your table.

# About
Mangan Tako is a restaurant website showcasing traditional Cordilleran cuisine to promote Cordilleran culture through food and a virtual showcase using web design.

# Features
- Simple Hero page
- Photo gallery
- Interactive menu

# Tech Stack
- HTML
- CSS

# Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` from
the project directory and visit `http://localhost:8000`.

The contact form is currently unavailable until a submission service is
configured. Social icons are placeholders without profile links.
